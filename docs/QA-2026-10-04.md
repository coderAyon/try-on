# Verification — 4 October 2026

## Passed checks

- Production TypeScript/Vite build.
- Stability: stationary rotation, bridge and scale noise; motion lag; reacquisition; zoom at 20/30/60 FPS.
- Blink/squint sizing across all 32 bundled frame profiles, with real distance changes.
- 1,200 frame-specific scale samples.
- Temple trimming preserves front geometry, UVs and material groups.
- Camera request serialization, cancellation cleanup, busy-camera fallback and permission denial.
- 33 local catalog models: 2 reference faces, 6 poses each (396 rendered poses), with no placement audit issues.
- All 33 models switched and rendered in a simulated live camera stream.
- Fit advisor measured a face, produced recommendations and updated live comparison when selecting a frame.
- Carousel autoplay, pause, unchanged worn selection, desktop alignment and mobile overflow.
- Mobile portrait upload produced a 2048 × 2048 fitted image; comparison, zoom and download were available.
- Local mobile widths 320/375/390/430 px: no horizontal page overflow. Public mobile layout at 390 px also passed.
- Public Vercel catalog returned JSON; photo proxy returned an image; unsupported URL protocol returned HTTP 400.

## Repairs made during verification

- Camera retry now relaxes all video constraints after a device startup failure. The primary request still prefers 60 FPS.
- Browser capability detection is guarded in non-browser tests.
- Older camera/carousel assertions were updated for camera consent, the expanded catalog and persistent advisor comparison.
- Added a photo end-to-end regression covering upload, output resolution, zoom, download and rejection of a no-face image without stale output.

## Limits

- A simulated camera validates the rendering and scan flow, not physical head movement, actual 60 FPS throughput or real iOS/Android camera permissions.
- Paid AI enhancement is not verified: the deployed server has no configured OPENAI_API_KEY and correctly returns HTTP 503. Local photo fitting works independently.
- Vite reports a large JavaScript chunk warning; the production build succeeds.
- Runtime telemetry changes in server/data/store.json are excluded from the source commit.
